StudyMate – Student Task & Deadline Manager

About the Project

StudyMate is a student task and deadline management application developed to help students organize their academic activities in one place.

It allows students to manage assignments, track pending and completed tasks, maintain a weekly timetable, and plan their daily study hours.

Features

- Dashboard: Displays total, pending, and completed tasks.
- Task Management: Add, edit, delete, and mark tasks as completed.
- Search Tasks: Find tasks using their title or subject.
- Filters: Filter tasks by status and subject.
- Progress Tracking: View task completion progress.
- Weekly Timetable: Organize and manage class schedules.
- Study Planner: Set daily study goals and track study hours.
- Dark Mode: Switch between light and dark themes.
- Local Storage: Saves tasks and preferences in the browser.
- Responsive Design: Supports desktop and mobile screens.

Technologies Used

- Next.js
- React
- TypeScript
- CSS
- Browser Local Storage

Getting Started

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_LINK

2. Open the project folder

cd student-task-manager

3. Install dependencies

npm install

4. Run the application

npm run dev

Open "http://localhost:3000" in your browser.

Purpose

The main purpose of StudyMate is to reduce confusion caused by managing academic tasks across different platforms. It provides a simple and organized workspace to help students plan their studies and track their progress.
