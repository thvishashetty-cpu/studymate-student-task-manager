StudyMate – Design System

1. Overview

StudyMate uses a simple, clean, and student-friendly interface. The design focuses on making academic task management easy and organized.

2. Design Goals

- Keep the interface simple and easy to understand.
- Make important information easy to find.
- Provide a consistent design across all pages.
- Support both desktop and mobile screens.
- Improve readability and usability.

3. Colour Theme

StudyMate supports two themes:

- Light Mode: Light backgrounds with dark text for comfortable reading.
- Dark Mode: Dark backgrounds with light text for use in low-light environments.

Buttons, task priorities, progress indicators, and navigation elements use contrasting colours to make them easy to identify.

4. Typography

- Use clear and readable text.
- Use larger and bold text for page headings.
- Use medium-sized text for section headings.
- Use regular text for descriptions and task details.

5. Layout

The application contains:

- Sidebar navigation for accessing different sections.
- Top navigation area for the page title and theme control.
- Dashboard cards for displaying task statistics.
- Main content area for task management.
- Separate sections for the timetable and study planner.

6. Components

Dashboard Cards

Display total tasks, pending tasks, completed tasks, and progress.

Task Cards

Display task title, subject, priority, due date, and completion status.

Buttons

Used for adding, editing, deleting, and completing tasks.

Search and Filters

Help students find tasks by title, subject, and completion status.

Timetable

Displays and manages the weekly class schedule.

Study Planner

Allows students to set daily study goals and monitor their progress.

7. Responsive Design

The application adjusts its layout according to screen size.

- Desktop: Sidebar and dashboard layout.
- Tablet: Adjusted content arrangement.
- Mobile: Compact layout with accessible navigation and content.

8. Accessibility and Usability

- Use readable text and sufficient contrast.
- Provide clear labels for buttons and inputs.
- Keep navigation consistent.
- Display task information in an organized manner.

9. Conclusion

The StudyMate design system provides a consistent and user-friendly interface that helps students manage their academic tasks, timetable, and study goals efficiently.
